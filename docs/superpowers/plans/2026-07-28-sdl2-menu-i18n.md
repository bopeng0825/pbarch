# SDL2 Menu Background, TTF, and Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an SDL2-only, low-overhead menu renderer with a cached image background, resolution-aware TTF text, and English, Simplified Chinese, and Traditional Chinese UI catalogs selected by global configuration and an optional command-line override.

**Architecture:** Pure C modules own catalog lookup, argument/config parsing, UTF-8 layout, and bounded LRU accounting so they can be tested without SDL. An SDL2 adapter loads and scales resources once, rasterizes each distinct string once through SDL_ttf, and blits cached surfaces into the existing RGB565 menu framebuffer. Small guarded hooks in `libpicofe/menu.c` replace byte-counted fixed-font layout only when `USE_SDL2` is enabled.

**Tech Stack:** C99, SDL2, SDL2_ttf, libpng, RGB565 framebuffers, Python 3 plus fonttools for developer-side catalog/font generation.

## Global Constraints

- Enable the new renderer only for `USE_SDL2`; SDL1, FunKey, and other platform behavior must remain unchanged.
- Translate only picoarch-owned UI strings; libretro core option names and values remain core-provided UTF-8.
- Use `en`, `zh_CN`, and `zh_TW`; accept `zh-CN` and `zh-TW` aliases; fall back to `en`.
- Resolve language with `command line > ~/.picoarch/ui.cfg > en`; a command-line override must not be persisted.
- Compute `main_px = clamp(round(menu_height / 24), 12, 32)` and `small_px = round(main_px * 0.8)`.
- Do not perform file I/O, PNG scaling, font opening, or TTF rasterization repeatedly in the steady-state menu frame loop.
- Bound the rendered-text cache and evict least-recently-used entries.
- Use `skin/background.png`, with a built-in RGB565 solid-color fallback.
- Bundle a UI-only Noto Sans Mono CJK subset and the SIL Open Font License 1.1.
- Preserve the original checkout's unrelated uncommitted `plat_h150101.c` change.
